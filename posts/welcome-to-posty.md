# Welcome to Posty!

Welcome to your new **Markdown blog app**! This is a sample post to get you started.

## What is Posty?

Posty is a simple, lightweight blog application built with Node.js that allows you to:

- Write posts in Markdown
- View all your posts in a clean list
- Read full posts with beautiful formatting
- Create new posts easily with a web form

## Markdown Support

You can use all standard Markdown formatting in your posts:

### Text Formatting

- **Bold text** with double asterisks
- *Italic text* with single asterisks
- `inline code` with backticks

### Lists

Unordered lists:
- Item one
- Item two
- Item three

Ordered lists:
1. First item
2. Second item
3. Third item

### Links and More

You can add [links like this](https://www.markdownguide.org/) to external resources.

## Getting Started

Click on "Create New Post" to write your own blog posts. All your posts are stored as Markdown files in the `posts` folder, making them easy to backup and version control.

Happy blogging! 📝
